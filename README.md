# 아하 속도 계산기

GitHub Pages에서 바로 게시할 수 있는 정적 웹사이트입니다. 별도의 빌드나 서버가 필요하지 않습니다.

## 게시 방법

1. GitHub에서 새 저장소를 만듭니다. 공개 사이트로 게시하면 저장소와 파일이 인터넷에 공개될 수 있습니다.
2. 이 폴더 안의 `index.html`, `.nojekyll`, `README.md`를 저장소 최상위(root)에 올립니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment**의 Source를 **Deploy from a branch**로 설정합니다.
5. Branch를 `main`, 폴더를 `/(root)`로 선택하고 **Save**를 누릅니다.
6. Pages 화면에 표시되는 사이트 주소를 엽니다. 게시 완료까지 잠시 걸릴 수 있습니다.

저장소 루트에 `index.html`이 있어야 첫 페이지로 열립니다.
